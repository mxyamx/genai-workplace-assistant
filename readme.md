# 🚀 GenAI Workplace Assistant & Playbook Generator

An internal enterprise AI portal prototype built for Investment firms (Technology, Data, and Operations group), designed to streamline secure generative AI adoption, Microsoft 365 Copilot integration, and structured workflow automation across business lines.

## ✨ Key Features
* **Internal AI Assistant Chat:** Answers employee queries regarding secure prompt patterns, document sensitivity classification, and M365 Copilot best practices.
* **AI Playbook Generator:** Converts unstructured brainstorming meeting notes into standardized, multi-section enterprise AI integration playbooks.
* **Live Adoption Metrics & Telemetry:** Tracks real-time system usage, generated playbooks, and user feedback logs.
* **Enterprise Guardrails & Fallbacks:** Engineered with resilient multi-model model fallback logic and automated retry handling to ensure 100% uptime.

## 🛠️ Tech Stack
* **Backend:** FastAPI, Python, Pydantic, Uvicorn
* **AI Engine:** Google GenAI SDK (`google-genai`), Gemini Flash models
* **Frontend:** HTML5, Bootstrap 5, Custom CSS/JS
